# Група „Икономисти“: цени, заплати, печалба

Кръчмата е бизнес. Собственикът решава цените и заплатите (клавиш **M**), а в края на всеки ден (22:00) вижда отчета: приходи, разходи, печалба и звездите на кръчмата.

## 1. Разберете числата

Отворете `data/sklad.json` и `data/items.json` и попълнете таблица (в тетрадка или Excel):

| Ястие | Цена в менюто | Продукти (от рецептата) | Колко струват продуктите за 1 порция | Печалба от 1 порция |
|---|---|---|---|---|
| Шопска | 10 | домат, краставица, чушка, лук, сол, олио, оцет, сирене | ? | ? |

Цена на 1 порция продукт = цена на пакета ÷ порции в пакета (например сирене: 10 ÷ 10 = 1).

## 2. Опит: каква цена носи най-много пари?

Играйте по 1 ден (около 7 минути) с различни цени и запишете отчета:

| Опит | Цени | Гости | Ядосани | Приходи | Продукти | Заплати | Печалба | Звезди |
|---|---|---|---|---|---|---|---|---|
| 1 | нормални | | | | | | | |
| 2 | +40 % | | | | | | | |
| 3 | двойни | | | | | | | |
| 4 | -30 % | | | | | | | |

Въпроси:
- Защо при двойни цени печалбата пада, въпреки че всяко ястие носи повече?
- Какво става на **следващия** ден, ако звездите паднат?
- Кой гост първи казва „Всичко е прекалено скъпо!“ и защо (вижте `пести` в `data/gosti.json`)?

## 3. Опит: заплати и персонал

- Намалете заплатата на сервитьора наполовина. Какво става с бързината и с ядосаните гости?
- Уволнете чистача. Колко време минава, докато свършат чистите чинии?
- Кое е по-изгодно: да платиш заплата или да губиш гости?

## 4. Предложете промени

Напишете предложение до учителя: нова цена, нова заплата, повече чинии (`"чинии"` в `sklad.json`), друго работно време (`"отваря"`, `"затваря"` - в минути от полунощ: 480 = 08:00). Обяснете с числата от опитите.
