# Работа по Real Life от два компютъра (GitHub Desktop)

## Еднократно - на ПЪРВИЯ компютър (където е D:\Real Life)
1. Изтегли и инсталирай **GitHub Desktop**: https://desktop.github.com
2. Влез с GitHub акаунта си (ако нямаш - "Create account" на github.com).
3. **File → Add local repository…** → избери `D:\Real Life` → **Add repository**.
   Ако пита за "unsafe/dubious ownership" - натисни бутона да добави изключение.
4. Долу вляво в **Summary** напиши `Първа версия` → **Commit to main**.
5. Горе: **Publish repository** → остави отметката **Keep this code private** → **Publish**.

## Еднократно - на ВТОРИЯ компютър
1. Инсталирай GitHub Desktop и влез със **същия** акаунт.
2. **File → Clone repository…** → избери `Real Life` → Local path: `D:\Real Life` → **Clone**.
3. Пусни `install.bat` (слага Python и pygame).
4. В приложението Claude отвори разговора → **+ → Add folder** → `D:\Real Life`.

## Всеки ден
- **Като СЕДНЕШ да работиш:** GitHub Desktop → **Fetch origin**, после **Pull origin**.
- **Като СТАНЕШ:** напиши кратко описание в Summary → **Commit to main** → **Push origin**.

Ако забравиш Push, на другото място няма да има последните промени.
Ако все пак си работил на двете места, GitHub Desktop ще покаже конфликт - извикай Claude да го оправи.

## Какво НЕ се качва (виж .gitignore)
`__pycache__`, `_to_delete`, `Claude outputs` - временни файлове.
